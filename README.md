# Transmission Hologram — Интерактивный учебник

Веб-приложение для изучения физики трансмиссионной голографии. Охватывает всё: от оборудования и оптической схемы до математики и интерактивных симуляций. Интерфейс на русском и узбекском языках.

---

## Стек

| Слой | Технологии |
|---|---|
| Фреймворк | Next.js (App Router), React 19, TypeScript |
| Стили | Tailwind CSS v4, CSS-переменные (тёмная тема) |
| Анимации | Canvas API (`requestAnimationFrame`), SVG-анимации |
| 3D | Three.js (вкладка «Симулятор восстановления») |
| i18n | React Context (`LanguageContext`) + типизированный словарь `lib/translations.ts` |

| 1 | Светоделитель | циан | 50/50 или 1:3, угол 45° |
| 2 | Зеркало | серый | Отражение >99%, микроюстировка |
| 3 | Линза-расширитель | зелёный | f = −10…−50 мм, расширение до 30 см |
| 4 | Объект | янтарный | 3D, диффузная поверхность |
| 5 | Голографическая плёнка | фиолетовый | 1000–5000 лин/мм, эмульсия 5–15 мкм |

### 1. Оптическая схема (`OpticalScheme.tsx`)

Интерактивный SVG 650×340. Компоненты — прямоугольники с hover-подсветкой. При наведении на компонент внизу появляется info-панель с описанием.

**Анимация лучей:** `requestAnimationFrame` двигает 3 точки по контрольным точкам опорного пути и 3 точки по объектному пути. Точки мигают через встроенный SVG `<animate>`.

**Оптическая схема:**
```
Лазер → Светоделитель ─→ Зеркало 1 → Линза 1 ──────────────┐
                    │                                      Плёнка
                    └→ Зеркало 2 → Линза 2 → Объект (рассеяние)┘
```

Угол θ между лучами на плёнке обозначен дугой с подписью.

Легенда: опорный луч (циан) / объектный луч (фиолетовый).

Ниже SVG — 2 карточки: описание опорного и объектного лучей, и 2 монохромные нотки с формульными ремарками.

### 2. Запись голограммы (`Recording.tsx`)

Пошаговая анимация (5 шагов) на Canvas 700×260. Каждый шаг — отдельная функция рисования `STEPS_DRAW[n](ctx, time, w, h)`.

| Шаг | Что показывается |
|---|---|
| 1 | Лазер включился — анимированный луч с градиентом |
| 2 | Светоделитель разделяет луч: опорный (циан) и объектный (фиолетовый) расходятся |
| 3 | Объектный луч падает на объект, рассеивается (7 веерных лучей с фазой `φ(x,y,z)`) |
| 4 | Оба луча встречаются на плёнке — анимированная интерференционная картина, формула `I = Aᵣ² + A₀² + 2AᵣA₀cos(φ)` |
| 5 | Готовая голограмма: плёнка с полосами, формулы d, N, T(x,y) |

Навигация: кнопки шагов вверху + кнопки «←Назад / Далее→» внизу.

### 3. Математика (`Math.tsx`)

Самая насыщенная вкладка. Четыре блока.

#### Блок A — Таблица формул (2 колонки, `.formula-box`)

| Формула | Смысл |
|---|---|
| `Eᵣ = Aᵣ · exp(i·k·r)` | Опорный луч |
| `E₀ = A₀ · exp(i·k·r + i·φ(x,y))` | Объектный луч |
| `I = \|Eᵣ + E₀\|²` | Интенсивность на плёнке |
| `d = λ / (2·sin(θ/2))` | Период интерференционных полос |
| `N = 10⁶ / d` | Необходимое разрешение (лин/мм) |
| `Lc = λ² / Δλ` | Длина когерентности |
| `α = arcsin(λ/d)` | Угол дифракции 1-го порядка |
| `T(x,y) = T₀ + β·I(x,y)` | Пропускающая функция плёнки |

#### Блок B — Интерактивный калькулятор

Три параметра (слайдер + числовой ввод):

| Параметр | Диапазон | По умолчанию |
|---|---|---|
| λ (длина волны) | 380–780 нм | 632.8 нм |
| θ (угол между лучами) | 1–90° | 30° |
| Δλ (ширина линии) | 0.001–1 нм | 0.01 нм |

Результаты (4 плитки, реальное время):

| Результат | Формула | Цвет |
|---|---|---|
| d — период полос | λ / (2·sin(θ/2)) | циан |
| N — разрешение | 10⁶ / d | фиолетовый |
| Lc — длина когерентности | λ² / Δλ | зелёный |
| α — угол дифракции | arcsin(λ/d) | янтарный |

Статус N: зелёный «обычная плёнка подойдёт» если N ≤ 5000, оранжевый «нужна специальная плёнка» если N > 5000.

Все результаты экспортируются в `window.__HOLOGRAM_DATA__` для внешних инструментов.

#### Блок C — Пошаговое вычисление

4 раскрашенных `.formula-box` с живыми подставленными значениями. Каждый шаг подсвечивает промежуточные числа цианом, итог — зелёным.

#### Блок D — Справочник формул

6 карточек (по одной на формулу) с полями: **Когда** применять, **Зачем** нужна, **Типичный результат** с конкретными числами.

### 4. Восстановление (`Reconstruction.tsx`)

Canvas-анимация 720×280 на `requestAnimationFrame`. Показывает:

- голографическую плёнку с интерференционными полосами
- опорный луч (параллельные горизонтальные волны) с анимированной стрелкой
- три выходящих пучка:
  - **0-й порядок** — прямо насквозь (белый, пунктир)
  - **+1-й порядок** — вверх-вправо (циан, яркий, движущаяся точка) → «Восстановленное изображение!»
  - **-1-й порядок** — вниз-вправо (фиолетовый, пунктир) → «Сопряжённая волна»

Математика восстановления (4 члена раскладки `E_out = T(x,y)·Eᵣ`):

```
E_out = T₀·Eᵣ                      — прямое прохождение
      + β·Aᵣ²·Eᵣ                   — фоновая волна
      + β·Aᵣ·A₀·exp(iφ)   ← ГОЛОГРАММА (подсвечено)
      + β·Aᵣ·A₀*·exp(-iφ)          — псевдоскопическое изображение
```

Ниже — подсвеченный блок с объяснением и три карточки 0 / +1 / -1 порядков.

### 5. Фрагмент голограммы (`HologramPiece.tsx`)

Демонстрирует ключевое свойство голограммы: каждый фрагмент содержит полное изображение (с меньшим углом обзора).

4 варианта фрагмента:

| ID | Доля | Угол обзора |
|---|---|---|
| full | 100% | 40° |
| half | 50% | 20° |
| quarter | 25% | 10° |
| piece | 10% | 5° |

SVG 260×200: слева — плёнка с полосами и подсвеченным фрагментом, веер из центра с меткой угла, значок глаза наблюдателя.

Сравнение фото vs голограмма:
- **Фото:** 1 пиксель = 1 точка, локальная запись, при повреждении теряется часть
- **Голограмма:** каждая точка = вся информация, распределённая запись, при обрезке — только сужение угла

Аналогия окна: маленький кусок голограммы — как маленькое окно на большой мир.

### 6. Сравнение (`Comparison.tsx`)

Трансмиссионная vs отражательная голограмма.

**Два SVG-диаграммы:**

*Трансмиссионная:* Лазер и наблюдатель по одну сторону плёнки. Восстановление лазером.

*Отражательная:* Белый свет падает с одной стороны, наблюдатель с той же. Объект на другой стороне плёнки. Восстановление белым светом.

**Таблица сравнения** (8 строк): источник восстановления, расположение наблюдателя, цветность, толщина эмульсии, угловая избирательность, применение и др.

Два блока преимуществ (4 пункта каждый) для каждого типа голограмм.

### 7. Оптический стол (`OpticalTable.tsx`)

Полноценный интерактивный симулятор оптической схемы на Canvas.

**Размеры:** 800×550 пикселей. Слева — палитра (90 px), справа — рабочий стол (710×550).

#### Компоненты (6 типов)

| Тип | Отображение | Поведение при попадании луча |
|---|---|---|
| `laser` | Красный прямоугольник + стрелка | Источник луча |
| `beamsplitter` | Жёлтый квадрат с диагональю | Делит луч 50/50: прямо + отражение |
| `mirror` | Тонкий серебристый прямоугольник | Отражает (потеря 5% интенсивности) |
| `lens` | Двояковыпуклая линза (циан) | Веер из 3 лучей (−15°, 0°, +15°) |
| `object` | Фиолетовый круг | 7 рассеянных лучей в сторону плёнки |
| `film` | Янтарный прямоугольник с полосами | Фиксирует hit, луч останавливается |

#### Управление

| Действие | Результат |
|---|---|
| Клик на палитру | Добавить компонент в центр стола |
| Перетащить компонент | Переместить |
| Выбрать → тянуть круглый handle над ним | Повернуть мышью |
| Колёсико над компонентом | Повернуть на ±5° |
| Клик в пустоту | Снять выделение |

После выбора компонента появляется control bar:
- числовой ввод угла
- кнопки ±1°, ±5°, ±15°, ±45°
- кнопки снапа к 0°, 45°, 90°, 135°, 180°
- кнопка «🗑 Удалить»

#### Пресеты

| Название | Описание |
|---|---|
| Стандартная | Лазер → БС → 2 зеркала + 2 линзы → объект → плёнка |
| Пустой стол | Чистый стол |
| Ошибка (нет БС) | Лазер → объект → плёнка (интерференции нет) |
| Прямоугольник | Опорный луч идёт по прямоугольному пути |
| Треугольник | Опорный луч идёт по треугольному пути |
| Габор (in-line) | Без светоделителя: объект в прямом пучке |
| Расширенный | Линзы в обоих плечах |

#### Трассировка лучей (алгоритм)

BFS-очередь (`RaySource[]`). Каждый луч трассируется до ближайшего пересечения с компонентом через `segmentsIntersect`. Максимум 10 отражений, минимальная интенсивность 0.05. Лучи отрисовываются с `shadowBlur` и двумя проходами (тонкий + glow).

#### Живая симуляция (3 секции)

**A. Длины оптических путей:**
- длина опорного пути (сумма сегментов `r.rayType === 'reference'`)
- длина объектного пути
- разность vs длина когерентности (40 000 px ≈ 40 мм)
- статус «✓ В пределах когерентности» / «✗ Превышает»

**B. Картина интерференции:**
- Canvas 200×120
- пиксель-точная синусоидальная картина через `ImageData`: `I = (1 + cos(2πy/T + phase)) / 2`
- анимированные полосы
- подпись `d = … нм | N = … лин/мм`

**C. Чеклист компонентов:**
7 строк: лазер, светоделитель, зеркало, линза, объект, плёнка, интерференция — ✓/✗.

#### Туториал

Сворачиваемая панель с 5 шагами (последовательно зеленеют при выполнении):
1. Добавить лазер
2. Добавить светоделитель
3. Добавить плёнку
4. Добавить объект
5. Добиться интерференции на плёнке

### 8. Симулятор восстановления (`ReconstructionSim.tsx`)

3D-симулятор на **Three.js** (Canvas 800×420).

**Параметры записи (фиксированы):**
- λ_запись = 632.8 нм (He-Ne)
- θ_запись = 30°

**Интерактивные параметры восстановления:**
- Угол падения (слайдер 0–90°)
- Длина волны λ_восстановления (слайдер)

**Качество восстановления:**

| Условие | Статус |
|---|---|
| Δθ < 2° и Δλ < 5 нм | Идеальное восстановление |
| Δθ < 10° или Δλ < 20 нм | Частичное восстановление |
| иначе | Ошибка восстановления |

**Таблица лазеров:**

| Лазер | λ | Цвет | Цена |
|---|---|---|---|
| He-Ne | 632.8 нм | 🔴 | $50–200 |
| Аргоновый | 488 нм | 🔵 | $100–500 |
| Nd:YAG×2 | 532 нм | 🟢 | $10–50 |
| Диодный | 405 нм | 🟣 | $5–20 |

3D-сцена: `WebGLRenderer` с `AmbientLight` + `DirectionalLight`, `PerspectiveCamera` с орбитальным управлением мышью.

### 9. 2D → 3D Реконструкция (`FractalCNN.tsx`)

Интерактивный симулятор, демонстрирующий работу **Geometry-Aware Fractal CNN** для реконструкции 3D-объектов.

**Загрузка изображения:**
- Drag & drop или file-picker
- 3 встроенных примера: пирамида, сфера, куб (генерируются на offscreen canvas)

**Обработка (выполняется в браузере, без сервера):**

| Шаг | Что происходит |
|---|---|
| 1 | Изображение рисуется на canvas 128×128 |
| 2 | Из каждого пикселя извлекается яркость: `L = 0.299R + 0.587G + 0.114B` |
| 3 | Применяется box-blur (N проходов) для сглаживания |
| 4 | Карта глубины визуализируется как amber-тепловая карта |
| 5 | Создаётся `PlaneGeometry(4, 4, 127, 127)` в Three.js |
| 6 | Каждый из 128×128 вершин смещается по Z: `vertex.z = depth[i] * scale` |
| 7 | Исходное изображение применяется как текстура через `CanvasTexture` |

**Три.js визуализация:**
- Canvas 800×400, `WebGLRenderer`, `MeshStandardMaterial` с текстурой
- Освещение: AmbientLight (синий) + DirectionalLight (циан) + DirectionalLight (фиолетовый)
- Орбитальное управление: drag = вращение (theta/phi), колёсико = масштаб (radius)
- Авто-вращение по theta

**Контролы:**
- Масштаб глубины (0.2–4.0): как высоко торчат вершины
- Сглаживание (0–8): количество проходов box-blur
- Каркас: переключает `wireframe` у материала
- Авто-вращение: вкл/выкл
- Сброс: возврат к экрану загрузки

**Архитектура Fractal CNN (10 интерактивных шагов):**

| # | Название | Формула | Смысл |
|---|---|---|---|
| 1 | Геометрический объект | aᵢx+bᵢy+cᵢz+dᵢ=0 | Каждая грань — плоскость, нормаль + смещение |
| 2 | Индикаторная функция | F = ∏σ(aᵢx+bᵢy+cᵢz+dᵢ) | Мягкая принадлежность точки объекту через sigmoid |
| 3 | Градиент F | ∂F/∂x = Σaᵢσᵢ(1−σᵢ)∏σⱼ | Большой вблизи граней — указывает поверхности |
| 4 | Маскирование | X_masked = X ⊙ F | Пространственное внимание, подавление фона |
| 5 | Фрактальная свёртка | Y = Σ Wₛ × Xₛ | 3 масштаба (fine/medium/coarse), захват самоподобия |
| 6 | Механизм внимания | A = softmax(q(x)), Y = A ⊙ X | Усиление информативных зон |
| 7 | Residual блок 3D | Y = F(X) + X | Conv3D→BN→ReLU + skip-connection |
| 8 | Функция потерь | L = Lc + λLf + βLg | Cross-entropy + фрактальная + граничная потеря |
| 9 | Adam оптимизатор | θ ← θ − η·m/√(v+ε) | Адаптивный шаг для каждого параметра |
| 10 | Общая архитектура | Voxel→Indicator→Mask→Conv×3→FC | Полный конвейер от воксельной сетки до предсказания |

Клик по шагу раскрывает подробное объяснение на русском или узбекском.

**Pipeline-бар:** горизонтальная строка `3D Voxel → Indicator → Mask → Conv 1 → Attention → Conv 2 → FractalConv → Conv 3 → Pooling → FC → Output` всегда видна над шагами.

## Физика — краткая шпаргалка

| Формула | Назначение |
|---|---|
| `d = λ / (2·sin(θ/2))` | Период интерференционных полос на плёнке |
| `N = 10⁶ / d` | Необходимое разрешение плёнки (лин/мм) |
| `Lc = λ² / Δλ` | Максимальная глубина записываемой сцены |
| `α = arcsin(λ/d)` | Угол дифракции 1-го порядка при восстановлении |
| `I = Aᵣ² + A₀² + 2AᵣA₀cos(φ)` | Интенсивность на плёнке |
| `T(x,y) = T₀ + β·I(x,y)` | Пропускающая функция готовой голограммы |

- d ≈ 1223 нм = 1.2 мкм
- N ≈ 818 лин/мм (стандартная плёнка справляется)
- Lc ≈ 40 мм (при Δλ = 0.01 нм)
