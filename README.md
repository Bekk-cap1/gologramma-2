# Transmission Hologram / Fractal 3D Project

This project has two parts:

1. A Next.js frontend for the interactive hologram/fractal interface.
2. A Python FastAPI backend for CNN classification, depth/CRF tools, and 3D fractal reconstruction.

The frontend and Python backend run separately.

## Frontend Run

First time:

```powershell
cd C:\Users\Bol\Desktop\gologramma-2
npm install
npm run dev
```

Open:

```text
http://localhost:3100
```

Later runs:

```powershell
npm run dev
```

## Python Backend Run

First time:

```powershell
cd C:\Users\Bol\Desktop\gologramma-2
.\run_python.ps1 -Install
```

Later runs:

```powershell
.\run_python.ps1
```

Backend URL:

```text
http://127.0.0.1:8000
```

If PowerShell blocks the script, run:

```powershell
powershell -ExecutionPolicy Bypass -File .\run_python.ps1 -Install
```

Manual Python version:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m fractal_3d.api_server --host 127.0.0.1 --port 8000
```

## Run Full App

Use two terminals:

Terminal 1:

```powershell
npm run dev
```

Terminal 2:

```powershell
.\run_python.ps1
```

Then open:

```text
http://localhost:3100
```

## Project Structure

```text
app/                 Next.js pages and API routes
components/          React UI tabs/components
lib/                 Frontend helpers/renderers/translations
fractal_3d/          Main Python backend package
scripts/             Dataset, training, API, export helper scripts
model/               Trained CNN model files
public/              Static frontend assets
docs/diagrams/       Diagram source files only
requirements.txt     All Python dependencies
package.json         Node/Next.js dependencies and scripts
package-lock.json    Exact installed Node dependency versions
tsconfig.json        TypeScript config
run_python.ps1       Simple Python backend runner
```

## Important Files

```text
app/page.tsx                         main frontend page
fractal_3d/api_server.py             main Python API server
fractal_3d/pipeline.py               2D image -> fractal analysis pipeline
fractal_3d/neural_depth/             depth estimation and DCNF/CRF logic
scripts/train_cnn.py                 CNN training
scripts/generate_dataset.py          synthetic dataset generation
model/best_model.pt                  trained CNN model used by the backend
```

AGENTS.md, CLAUDE.md      AI-assistant instruction notes

## Why Some JSON Files Stay

These are required:

```text
package.json        tells npm what frontend packages/scripts to use
package-lock.json   locks exact frontend dependency versions
tsconfig.json       TypeScript compiler settings
```

Generated JSON files such as `manifest.json` and `transforms.json` are output files. They are ignored and should live under runtime output folders, not in the source project.

## Useful Python Commands

Run API:

```powershell
.\run_python.ps1
```

Run tests:

```powershell
.\.venv\Scripts\python.exe -m pytest fractal_3d/tests -q
```

Generate dataset:

```powershell
.\.venv\Scripts\python.exe scripts\generate_dataset.py --n 45000 --size 128 --out .\dataset
```

Train CNN:

```powershell
.\.venv\Scripts\python.exe scripts\train_cnn.py --epochs 100 --batch 64 --cls-only
```
